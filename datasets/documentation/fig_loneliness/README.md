# FIG-Loneliness Dataset Documentation

## 1. Dataset Overview

FIG-Loneliness is used for the project's Social Isolation / Loneliness Indicators module.

- Dataset: FIG-Loneliness
- Source: https://huggingface.co/datasets/FIG-Loneliness/FIG-Loneliness
- License: CC BY-NC 4.0
- Total records: 5,633
- Task: Binary text classification

## 2. Dataset Splits

| Split | Records | Lonely | Non-lonely |
|---|---:|---:|---:|
| train | 3943 | 1840 | 2103 |

## 3. Label Mapping

| Original vector | Numeric label | Meaning |
|---|---:|---|
| `[1, 0]` | 0 | non_lonely |
| `[0, 1]` | 1 | lonely |

- Total lonely records: 2,633 (46.74%)
- Total non-lonely records: 3,000 (53.26%)

## 4. Model Input and Target

- Model input: `text`
- Prediction target: `label`
- Label names: `lonely`, `non_lonely`

The other annotation fields are retained as metadata. They must not be included as model inputs in the baseline text-classification experiment.

## 5. Annotation Metadata

- `unique_id`: unique record identifier
- `idx`: original dataset index
- `lonely`: original two-element loneliness label vector
- `context_pri`: context annotation distribution
- `interaction`: interaction annotation distribution
- `interpersonal_pri`: interpersonal annotation distribution
- `temporal`: temporal annotation distribution

## 6. Cleaning and Standardization

- Removed leading and trailing whitespace only.
- Cleaned outer whitespace in 402 records.
- Removed zero records.
- Preserved duplicate text records.
- Preserved all annotation vectors.
- Converted original one-hot labels into numeric labels.
- Preserved official train, validation, and test splits.
- Long posts were not truncated during cleaning.

## 7. Quality and Leakage Checks

- Missing values: 0
- Invalid label vectors: 0
- Duplicate unique IDs: 0
- Duplicate indices within splits: 0
- Cross-split ID overlap: 0
- Cross-split exact-text overlap: 0
- All 67 standardized verification checks passed.

Two duplicated text groups were found in training. Both groups have consistent loneliness labels and were preserved.

## 10. Ethical Interpretation and Limitations

This dataset captures loneliness expressed in Reddit text. It does not measure objective social isolation and must not be used to diagnose loneliness or any mental health condition.

Predictions from this module are indicators for supportive conversation only. They must be interpreted cautiously and must not independently determine a student's mental health status.

## 11. Model Development Recommendation

- Input: text
- Output: 2-class prediction
- Output labels: non_lonely (0), lonely (1)
- Loss: CrossEntropyLoss
- Evaluation: Accuracy, Macro-F1, Weighted-F1, per-class Precision/Recall/F1, and Confusion Matrix
- Use training data for fitting, validation for model selection, and test data only for final evaluation.
